# Boocs Messenger

Полностью переделан в интерактивный messenger-demo для ролика (`npm start/index.html`):
- аккаунт: регистрация / вход / «реанимация»
- чаты: private/group/channel, поиск, отправка разных типов сообщений
- голосовые: запись удержанием, cancel swipe-left, lock swipe-up, playback speed
- видео-ноты: запись с камеры + shape (circle/square/triangle)
- звонки: audio/video, mute/cam/switch/record state
- сервисы: музыка, такси, метро, госуслуги
- настройки: PIN, тема, accent, preview/sounds

Все хранится в localStorage и работает в статическом Render-деплое.
